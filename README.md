# LinguaShield

LinguaShield is a multilingual, multimodal investigation platform designed to help users examine potentially suspicious communication. It brings several analysis capabilities into one workflow and presents findings to support human investigation; it does not guarantee that every scam or synthetic voice will be detected.

## Key Modules

- **Text Analysis** — examines suspicious messages and links for potential scam indicators.
- **Visual Analysis** — extracts and examines text and links found in images.
- **Acoustic Analysis** — checks audio for indicators that may be associated with synthetic speech.
- **Biometric Speaker Verification** — compares voice samples to estimate speaker similarity.
- **Live Analysis** — supports analysis of microphone input and prerecorded audio through available workflows.
- **TrustPath** — organizes and correlates evidence from supported modules.
- **LUI Investigation Copilot** — helps summarize and explain investigation findings.

## Technology

The project uses a Python backend with FastAPI and Uvicorn alongside a browser-based frontend. Depending on the module and configured environment, it uses machine-learning and audio-processing libraries, OCR tools, multilingual translation, and a locally run language model.

## Important Limitations

LinguaShield is an investigation aid, not a definitive fraud detector or identity-verification authority. Results depend on input quality, available evidence, model behavior, and configuration. Speaker similarity does not prove a person's identity, and an acoustic synthetic-speech score is not proof that audio was generated by AI. Comprehensive independent real-world evaluation is still needed.

## Running Locally

Follow the startup instructions and dependency files included in this repository. Review the configuration and ensure required model files and dependencies are available before running the project.

If your local setup uses a launcher such as `run.py`, check that file for the expected frontend/backend commands and ports. Do not commit local environment files, private credentials, large model weights, or datasets unless you have reviewed their licensing and repository suitability.

## Before Publishing

1. Review `.gitignore` and ensure required source files are not accidentally excluded.
2. Keep secrets in environment variables; commit a sanitized `.env.example` instead of `.env`.
3. Check licenses and terms for datasets, pretrained models, and third-party assets.
4. If large model files are required, consider Git LFS or a documented external download location.
5. Add a `LICENSE` file only after choosing the license you want for this project.

## Project Status

Academic project / research prototype. Detection behavior and reliability should be interpreted in light of the project's current testing and evaluation limitations.
